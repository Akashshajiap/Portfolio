# Akash A P - Data Analytics Portfolio

Welcome to the source code for my personal data analytics portfolio! This website is built using vanilla HTML, CSS, and JavaScript, featuring a dynamic 3D globe and a scroll-triggered canvas animation for a modern, glassmorphic UI.

## 🚀 Live Demo

[https://akashshajiap.github.io/Portfolio/](https://akashshajiap.github.io/Portfolio/)

## 🛠️ Built With

*   **HTML5 & CSS3:** Semantic structure and modern styling with Flexbox, CSS Grid, and custom animations.
*   **Vanilla JavaScript (ES6):** No heavy frameworks. JS is used for the smooth scroll-triggered canvas animation and timeline logic.
*   **FontAwesome:** For all the vector icons used in the timeline, skills, and contact sections.
*   **Model Viewer:** Used for the interactive 3D globe in the contact section.
*   **Google Fonts:** Utilizing 'Inter' for clean, readable typography.

## ✨ Key Features

*   **Dynamic Canvas Background:** A buttery-smooth, scroll-driven sequence of images mapped to the user's scroll position using `requestAnimationFrame` and linear interpolation (Lerp).
*   **Glassmorphism UI:** Frosted glass effects on project cards, timeline elements, and contact forms for a premium aesthetic.
*   **Smooth Navigation:** Seamless anchors across `index.html` and `projects.html`.
*   **Interactive 3D Elements:** A movable 3D Earth model integrated into the contact section.
*   **Fully Responsive:** Designed to look great on desktop, tablet, and mobile devices.

## 💻 How to Run Locally

1.  Clone this repository:
    ```bash
    git clone https://github.com/Akashshajiap/<your-repo-name>.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd <your-repo-name>
    ```
3.  Start a local server. You can use Python's built-in HTTP server:
    ```bash
    python -m http.server 8000
    ```
    *Alternatively, you can use the **Live Server** extension in VS Code.*
4.  Open your browser and visit `http://localhost:8000`
